# Archived documentation

These files were moved here to reduce clutter in the project root. They are kept for reference.

- **plans/** – Old action plans, development plans, implementation status
- **security-reviews/** – Phase reviews, one-off security analyses
- **fix-logs/** – One-off fix writeups (Git email, env loading, OAuth app name, etc.)
- **testing/** – E2E/test analyses, next-steps, and the original long testing guides (TESTING_GUIDE, TESTING_STRATEGY, TESTING_BEST_PRACTICES, etc.)
- **deployment/** – Deployment status and verification snapshots
- **backend/** – Backend-specific fix logs (REST Assured, test fixes, etc.)
- **frontend/** – Frontend test fix logs
- **oauth-stripe/** – Original OAuth/Stripe setup and troubleshooting docs (merged into docs/OAUTH_AND_STRIPE_SETUP.md)
- **session/** – Original session timeout and security docs (merged into docs/SESSION_AND_AUTH.md)
- **misc/** – Embeddings guides, Spring AI upgrade notes, cost/reverse-proxy docs

See **DOCUMENTATION_CLEANUP.md** in the project root for the full cleanup plan.
